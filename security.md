#Repository Security Statement
##Intended Users

This repository is intended for me and my professor to use for coursework and educational purposes.

##Security Risk Assessment

The security risk is low since this repository mainly contains files and code for coursework. However, unauthorized access could allow someone to copy my work. Accidentally sharing passwords or other sensitive information could also create security risks.

##Security Measures

Since this repository is mainly for individual coursework, additional security measures such as CODEOWNERS files and pull request rulesets are not necessary at this time. I will avoid committing passwords or other sensitive information and review changes before committing and pushing them.
